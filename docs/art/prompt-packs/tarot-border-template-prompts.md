# Tarot Border Template Prompts

Use these prompts with imagegen to create reusable blank border templates.
Generate one candidate per prompt, review, then save raw outputs under:

```text
assets/templates/minor-arcana/raster-border-templates/raw/
```

The center window should be flat `#00ff00` so it can be removed locally. Do not
ask imagegen for card titles or readable typography.

## Shared Negative Prompt

Avoid: readable text, pseudo-writing, letters, numbers, rank symbols, suit
words, card title, logo, watermark, bird character, human character, humanoid
figure, hands, clothing, weapon display, magical particles, spell circles,
floating runes, old-world parchment, plain medieval fantasy frame, sci-fi
hologram UI, cyberpunk paneling, circuit patterns, industrial machine parts,
antenna hardware, bolts as the dominant design language, thin cheap border,
cream simplified frame, crooked geometry, asymmetric frame, cropped corners,
center artwork, background scene inside the center window.

## Deck Style Reference

Use the existing full-card Minor Arcana art under
`.generated/imagegen/tarot/minor-arcana/` as the deck reference. Match the older cards'
hand-inked black-and-aged-gold tarot frame, colored enamel suit medallions,
organic filigree, illustrated weathering, and slightly magical storybook finish.
The border should read tarot-fantasy first, modern city second. Streetwear and
urban culture should appear as subtle worn-paint edges, sticker-wear shapes
without text, night-market color accents, and weathered city patina, not as hard
technology or futuristic equipment.
