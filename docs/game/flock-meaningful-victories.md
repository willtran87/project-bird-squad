# Flock + Meaningful Victories

Historical release record: the arbitrary supporting Leader bodies and atlas
presentation were retired by the [opening combat release](opening-combat-quality.md).
Its played-card cue identifies the actual acting bird. The objective victories,
reward, practice and local-feedback features remain current.

Requested 2026-10-29: implement the next improvement package, qualify the full release, publish Pages and clean up the feature branch.

## Acceptance ledger

- Objective victories: ferry survival, relay interception, rooftop escape, with disclosed defeat-all fallback/bonus; defeat takes precedence over victory.
- Visible flock: two supporting performers, bounded actor count, attack travel, defense advance, coordinated combinations and still-pose alternatives; no additional animation wait.
- Reward decisions: complete primary benefit sentences, explicit conditional limitations, useful full-rule fallback, preserved Read and exact passive deltas.
- Canal gift: automatic introduction after restoration, exclusive persistent choice, optional isolated demo and return to the real flight.
- Final-turn practice: exact hand/resources/enemies/random state restored, one-phase comparison, hidden future draws, memory-only progression.
- Local feedback: optional Confusing/Satisfying/Slow markers, bounded storage, export and clear; no automatic transmission.

All six packages and technical release gates are complete. The release is
deployed and verified; its feature branch was deleted locally and remotely.

Initial local checks: the previous 12 signature-fight cases and all seven new
feature cases passed. An additional catalogue check confirms every normal and
Preened primary benefit fits without ellipses. Visual review at 2560×1600,
1440×900 and 1000×560 led to separate wingmate positions, improved comparison
table spacing, removal of redundant portrait effects, and frame-driven pose
updates. The capstone demo suspends the real route; return preserves disk storage
byte for byte. Practice restores private RNG state and never exports future draws.
